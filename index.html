Qizil belgilar bilan belgilangan tugmalar

Klaviaturadagi yangi harflar matn terishda maksimal tezlikni ta'minlash uchun o'ng qo'lning eng qulay sohalariga joylashtirilgan:

  • [ Ö va ö harflari (P ning o'ngida)
  • ] Ğ va ğ harflari (Ö ning o'ngida)
  • ; Ş va ş harflari (L ning o'ngida)
  • ' Ç va ç harflari (Ş ning o'ngida)
  • \ ; (nuqtali vergul) va : (ikki nuqta)
  • ` ' (tutuq belgisi) va " (qo'shtirnoq)

Qanday o'rnatiladi?

Faqat 3 ta oddiy qadam — administrator huquqlari bilan bir zumda o'rnatiladi

1

Faylni yuklab oling

Yuqoridagi yashil tugma orqali YangiAlifbo_Setup.exe faylini kompyuteringizga yuklab oling.

2

1-klik bilan o'rnating

Faylni ikki marta bosing va oynadagi "Klaviaturani O'rnatish" tugmasini bosing.

3

Klaviaturani tanlang

Klaviaturada Win + Bo'sh joy (Space) tugmalarini bosib, til panelidan "Uzbek - new" ni tanlang.

Ko'p so'raladigan savollar

Dasturchilar uchun qavslar ([ ] { }) qayerga ketdi?

Barcha dasturlash qavslari o'z joyida saqlangan! Ularni yozish uchun o'ng tomondagi AltGr (o'ng Alt) tugmasini bosib turing. Masalan: AltGr + ö tugmasi [ belgisini, AltGr + Shift + ö esa { belgisini chiqaradi.

Qaysi Windows tizimlarida ishlaydi?

Dastur Windows 11, Windows 10, Windows 8 va Windows 7 (ham 64-bit, ham 32-bit arxitekturalari) bilan 100% mos keladi.

Keyinchalik o'chirib tashlash mumkinmi?

Ha, albatta. YangiAlifbo_Setup.exe faylini qayta ochib "O'chirish" tugmasini bosishingiz yoki Windows Sozlamalaridagi "O'rnatilgan ilovalar" bo'limidan bir zumda o'chirishingiz mumkin.
